# Правила работы над проектом

- Записывай все дальнейшие запланированные действия по проекту в `BACKLOG.md` до завершения текущей задачи. Когда план меняется, обновляй существующие пункты вместо создания дублей; выполненные пункты отмечай как завершённые.
- Сверяй реализацию с `PRODUCT_SPEC.md` и `ARCHITECTURE.md`. Если принятое решение меняет требования или архитектуру, обновляй соответствующий документ.
