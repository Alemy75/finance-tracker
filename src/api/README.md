# API

Сервисы запросов и мутаций по образцу `@mfa/bff-api`. Папка на домен: `config.ts` (адреса, ключи запросов), `query.ts` или `index.ts` (фабрики), `index.ts` (экспорт).

Фабрика `createX(deps)` получает зависимости из DI-контейнера и возвращает сервис — функцию, которую можно вызвать напрямую, с методом `.qo()` (параметры для `useQuery`) или `.mo()` (параметры для `useMutation`). Сервисы подключаются в `src/lib/di.ts`, компоненты вызывают их только через `di`.

Мутации локальных данных принимают `LocalMutationDeps`: проверяют данные по кэшу `getLocalData`, пишут в IndexedDB, обновляют кэш через `updateLocalData` и вызывают `onLocalChange`, который обновляет очередь и запускает синхронизацию.
