# Компоненты

Слои повторяют соглашения проекта mfa. Компонент может импортировать только из своего слоя и слоёв левее в таблице.

| Слой | Может использовать | DI | Данные |
| --- | --- | --- | --- |
| `ui` | `ui` | нет | только пропсы; разметка и простая интерактивность |
| `smart` | `ui`, `smart` | да | сущность уже загрузил родитель; компонент может менять её через мутации из `di` |
| `widgets` | `ui`, `smart`, `widgets` | да | сам получает свои данные через `di` и показывает свой скелетон |
| `pages` | `ui`, `smart`, `widgets` | да | компоновка виджетов и отступы между ними, без собственной логики данных |

## ui

UI Kit на [shadcn/ui](https://ui.shadcn.com/) и презентационные компоненты приложения (карточка баланса, строки операций). Внешних отступов у компонентов нет. Новые компоненты shadcn добавляются командой `pnpm dlx shadcn@latest add <имя>`; импорт иконок из `lucide-react` в них заменяется на `@/components/ui/icons`.

## smart

Папка на компонент: `Name.tsx` и `index.ts`. Проп `di` обязателен.

## widgets

Папка на виджет в kebab-case:

- `Name.tsx` — виджет и его скелетон; содержимое обёрнуто в `SkeletonSwap`;
- `types.ts` — пропсы: `di` и, если виджет стоит на странице, `skeleton?: boolean` — показать скелетон, пока проверяется вход;
- `index.ts` — публичный экспорт.

У виджета нет внешних отступов — их задаёт страница. Скелетон собирается из тех же компонентов и классов, что и контент, а текст заменяет `SkeletonText`; основные блоки помечены `data-sk`. После изменения разметки проверьте совпадение на `http://127.0.0.1:5173/?skeleton`.

## pages

Папка на страницу: `NamePage.tsx` и `index.ts`, пропсы — `PageProps` из `pages/types.ts`.
